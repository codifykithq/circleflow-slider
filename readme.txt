A modern responsive circular image slider with circular labels, Elementor support and customizable visual controls.

== Description ==
CircleFlow Slider creates circular image sliders with rotating labels, blurred image backgrounds, responsive sizing, autoplay and navigation controls.

== Installation ==
1. Upload and activate the plugin.
2. Open CircleFlow Slider > Add New Slider.
3. Configure Slider Studio and add slides.
4. Use [circular_slider id="123"] or the Elementor widget.
