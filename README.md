# CircleFlow Slider – Circular Image Slider for WordPress

A responsive circular image slider for WordPress with circular labels, blurred backgrounds, autoplay, navigation controls and Elementor support.

## Features

- Responsive desktop, tablet and mobile circle sizing
- Circular clickable text labels
- Center-image crop and focus controls
- Optional separate background image per slide
- Background blur, opacity and scale controls
- Customizable active text arc
- Customizable navigation buttons
- Autoplay with browser visibility handling (no catch-up burst after inactive tabs)
- Pause on hover
- Keyboard navigation
- Shortcode support
- Elementor widget

## Shortcode

```text
[circular_slider id="123"]
```

## Requirements

- WordPress 6.5+
- PHP 8.0+
